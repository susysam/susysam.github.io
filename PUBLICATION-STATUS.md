# Publication status

This release is approved for GitHub publication. The intended target is `susysam/susysam.github.io`, branch `main`.

Check [GitHub Actions](https://github.com/susysam/susysam.github.io/actions) for deployment status and [the live site](https://susysam.github.io/) for the result. The Desktop handoff has the verified release commit and completion result after publication.

Firebase Hosting and updated Firestore rules are not deployed by the GitHub Pages workflow. Follow FIREBASE-QUICK-START.md for those separate steps. Timezone cloud saving requires the updated rules. GitHub publication does not change Firebase billing or create deployment credentials.
